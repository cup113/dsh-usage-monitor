# v2.0.3 侧栏用量浮卡

## 实现范围

按用户最新要求，在 v2.0.1 的界面结构和共享数据控制器基础上实现参考图效果。新建 `UsagePopover` 组件，不移植旧版弹出层的运行逻辑，继续保留 v2.0.2 的插件启停与路由清理修复。

点击完整、紧凑或图标侧栏入口，显示锚定入口的用量浮卡。浮卡优先放在入口上方，空间不足时调整位置，并随窗口尺寸及滚动重新定位。内容超过可用高度时供应商列表滚动，底部操作仍可访问。

浮卡显示已添加供应商的主指标、查询状态、刷新间隔和上次刷新时间。多币种余额保留额外指标提示；未知值保持未知，真实零值正常显示，查询失败保留已有成功数据。手动刷新与现有面板共用控制器，不增加独立轮询。

底部“详情”打开完整供应商分栏明细及历史表格，“设置”进入现有配置面板，“关闭”收起浮卡。再次点击入口、Esc、外部点击或焦点移出也可关闭。浮卡不遮挡整个宿主、不锁定页面滚动，关闭按钮和 Esc 关闭后焦点返回入口，外部点击保留目标焦点。
